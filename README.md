# Agent Skills

Agent skills for repository work.

| Skill | What it does |
| --- | --- |
| [draft-commit](draft-commit/SKILL.md) | Drafts a Conventional Commits message from the staged changes. Never commits. |
| [draft-pr](draft-pr/SKILL.md) | Drafts a pull request title and body from the current branch's commits. Never pushes or opens the PR. |
| [document-code](document-code/SKILL.md) | Writes or reviews names, comments, docstrings, Terraform descriptions, and shell script usage text. |
| [document-repo](document-repo/SKILL.md) | Writes, reviews, or audits READMEs, ADRs, CONTRIBUTING guides, changelogs, architecture docs, and runbooks. |
